`stt-test.pcm` is a synthetic Korean narration fixture from the preserved SYNC prototype's `intro.wav`, resampled from 22050 Hz mono PCM to 16000 Hz 16-bit little-endian mono PCM (6.698125 seconds). It is used only through official ON_DEVICE `sendAudio()` in debug builds, labeled TEST_PCM, and never dispatched as user consent or a vehicle command. It does not test a live microphone or human speech. Debug assets and TestReceiver are absent from release APKs.
