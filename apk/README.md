# APK

검증 묶음 ZIP의 `apk/PleosTutorial-1.0.0.apk`가 서명한 제출 후보 APK다. 소스 ZIP과 Git 일반 이력에는 대형 APK를 포함하지 않는다. GitHub 저장소를 지정한 뒤 Release 첨부파일의 고정 다운로드 링크를 이 문서에 연결한다.

앱 ID `kr.pleosguide`, versionName 1.0.0, versionCode 1. 제출 앱 소스 기준 commit은 `4fe8a913b52770218757791bf1749c2fb8b35ef9`다. 해시와 최종 제출 commit은 묶음의 `submission-manifest.json`을 확인한다.

서명 인증서 SHA-256: `7ce80baff526cfae8a27a61c4a4ee29336f58fd377e7139bd149236e1e51e016`.

`apksigner verify --print-certs`를 통과했다. debug TestReceiver 및 합성 PCM은 release에서 제외된다. 공식 Pleos 차량 SDK가 필요한 앱이며 일반 Android 휴대전화 지원을 주장하지 않는다.
