# Experio(Agentic Tutorial) 공개 기획 초안

오황 팀의 현대자동차그룹 차량용 앱 개발 공모전 출품작입니다. 2026-11-15 확정한 팀명과 앱명을 반영했습니다.

[3쪽 작품 소개서 PDF](proposal-public.pdf)는 앱의 기획 의도, 다섯 고객 경험과 현재 구현을 영상 장면·실제 실행 화면과 함께 설명합니다. 2026-11-15 실제 문서·카탈로그를 참고해 새로 편집했으며, [편집 참고 자료](brief-design-notes.md)를 남겼습니다. 아래는 구현 범위를 자세히 설명하는 초기 기획 기록입니다.

2026-11-14 개발 증거 기준 공개 초안. 참가자 신상·동의·서명이 들어가는 공식 신청서를 대체하지 않는다.

## 1. 문제와 대상

새 차에 다양한 기능이 있어도 사용자는 익숙한 기능만 반복할 수 있다. 차량을 운전하는 능력과 새 디지털 메뉴를 익히는 능력은 다를 수 있다는 문제에서 출발했다. 초기 검증 대상은 Pleos 탑재 그랜저를 새로 이용하는 50~69세 운전자다. 연령별 기능 미인지율과 실제 학습 효과는 아직 검증하지 않은 가설이며 수치 성과를 주장하지 않는다.

## 2. 제안하는 경험

사용자가 튜토리얼 모드를 켜면 차량 상태와 명시적으로 전달한 불편을 연결한다. 필요한 기능의 존재와 쓰임을 짧게 소개하고, 체험 수락 후 가능한 제어 또는 순정 조작 방법을 안내한다. 차량이 실제로 바뀌었는지와 사용자가 어떻게 느꼈는지를 따로 기록한다. 이후 스스로 다시 사용한 경험을 응답으로 남길 수 있다.

제품 목표는 원래 차량 기능·인터페이스·음성 안에서 배우는 경험이다. 현재 앱 화면은 정차 중 기능 진입·설정·시험을 위한 경로이며, 매번 앱으로 돌아와야 하는 흐름을 최종 경험으로 확정하지 않는다. 이번 제출판은 P 상태 상세 안내와 공개 SDK로 확인 가능한 범위를 우선 구현했다.

## 3. 다섯 체험

| 기능 | 발견할 가치 | 현재 구현 | 후속 검증 |
|---|---|---|---|
| SYNC | 동승자와 운전자가 서로 다른 온도를 선택할 수 있다 | 실제 SDK로 연동 해제·동승석 설정·좌우 결과 재조회 | 실차 사양·권한, 실제 음성 수락, 주행 중 짧은 안내 |
| 에르고 스트레칭 | 긴 주행 뒤 휴식 때 시트의 피로 완화 기능을 찾는다 | 장착 사양 조건, 버튼 전신→허리→골반→꺼짐 안내와 체감 기록 | 2시간 관측/P 전환 자동 제안, 실제 좌석 체감 |
| 사운드 위치·음장 | 전체 음량 외에 앞뒤 위치를 조절하고 음장은 별도로 비교한다 | 위치 안내, 가운데 복원 응답, 같은 곡·음량의 음장 비교 | 순정 오디오 권한·지원 사양, 실제 청취 비교 |
| SPREAD | 온도를 바꾸지 않고 얼굴에 닿는 직풍을 분산한다 | 직풍 발화 구별, 순정 공조 메뉴 안내, 목표온도 유지 관측 | 전동 벤트 모드 신호·제어, 실제 바람 체감 |
| Gleo 복합 요청 | 에어컨과 라디오 같은 요청을 한 문장으로 전달한다 | App Schema 3개 action, callback, 마이크 양보, A/C 부분 관측 | 실제 Gleo 자연어 왕복·복합 실행, 라디오 결과 |

## 4. 구현 구조와 차별점

차량 샘플에 영역·단위·시각·출처·지원성·오류를 함께 남긴다. 수락, 명령 전송, 차량 결과 확인, 체감 응답, 다음 사용 응답은 별도 상태다. 미지원 값은 false나 0으로 치환하지 않는다. 명령 ACK만으로 완료를 선언하지 않는다.

튜토리얼은 사용자가 켠 foreground service 한 개에서 동작한다. 한 번에 한 세션을 유지하고 중복·거절·무응답·주행 전환을 처리한다. 상시 주변 대화나 다른 앱의 메뉴 탐색을 감시하지 않는다. 공식 STT 세션, 앱 요청, Gleo action이 입력 경로다. 전용 API가 확인되지 않은 스트레칭·음장·SPREAD를 유사 제어로 흉내 내지 않는다.

## 5. 개발 계획에 넣을 문장

1차 제출 후보에서 Vehicle SDK 2.3.2와 공식 STT/TTS 3.3.1을 사용하는 단일 Android 앱을 구현했다. Pleos Connect 2.1.0 에뮬레이터에서 좌우 목표온도 21/21°C를 초기화한 뒤, 앱이 SYNC 해제와 동승석 24°C 명령을 보내고 별도 재조회로 운전석 21°C 유지·동승석 24°C·연동 해제를 확인했다. 수락과 체감 입력은 자동화된 시험이며 실제 사람 음성이나 사용자 연구 결과가 아니다.

에르고·사운드·SPREAD는 공식 매뉴얼에 근거한 순정 조작 안내와 사용자 응답 기록을 구현했다. Gleo는 최대 3개 App Schema action의 입력 검증과 success/asking/fail callback을 ADB로 시험했다. 공식 한국어 TTS 완료를 관측했으나 반복 실행의 시간 초과가 남아 있다. 실제 마이크 STT 및 Gleo 자연어 왕복은 미검증이다.

2차에서는 실제 사용자 발화와 Gleo 호출, 음성 충돌·focus 반환, 정상 메모리 조건의 반복 안정성, 장시간 주행 후 제안, 실차 사양별 권한과 메뉴, 기능 발견·재사용 효과를 검증한다. 검증이 끝난 범위부터 주행 중 짧은 안내와 기존 차량 UX 안의 진입을 확장한다. 확인되지 않은 전용 제어는 지원 경로를 확보할 때까지 수동 안내로 유지한다.
